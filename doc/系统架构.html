NRL 系统架构文档

NRL (Network Radio Link) — 通过网络连接无线电，实现跨地域、跨设备的语音互联系统

一、系统总览

NRL 系统由云端服务发现层、全球分布的 NRL 服务器集群、硬件终端、软件终端和辅助工具五个层次组成。服务器之间通过 APRS 网络和 nrlptt.com 官网双机制自动发现并建立互联，999 房间的语音在所有互联服务器之间自动转发。

发言机制详述

语音发言模式由在线设备数和房间类型共同决定，服务器自动切换，无需手动配置。

按在线设备数自动切换

在线设备数模式行为说明
1 台（非中继类型）回音反射服务器将该设备的音频原路反射回去，设备可听到自身语音，便于自检
2 台自动全双工服务器自动切换为全双工模式；ESP32 / App 类终端无需按住 PTT，可像电话一样自由通联
3 台及以上默认单工先到先得抢占发言权，PTT 松开后 200ms 释放，其他设备方可发言
所有模式下语音释放时间均为 200ms（松开 PTT 后）。

会议模式（Conference Mode）

任意房间均可由管理员开启会议模式，开启后覆盖上述单工/全双工规则：

  • 服务器端 PCM 混音：对同时到达的多路音频进行实时叠加混音
  • 全双工广播：混音结果转发给房间内所有在线设备
  • 无发言抢占：所有人可同时讲话，互不阻塞

四、全网互通（999 房间）数据流

999 房间是 NRL 系统的核心互联通道。用户在任意服务器的 999 房间发言后，语音帧会自动转发至所有互联服务器的 999 房间，实现全网通联。

图 04 — 999 全网互通时序

五、马工盒子射频桥接数据流

马工盒子是 NRL 系统的硬件核心，负责将本地无线电 RF 信号桥接到互联网。盒子内部完成 PTT 检测、G.711 编解码和 NRL 协议封装，通过 UDP 60050 端口与服务器通信。

六、部署架构

NRL 服务器支持三种部署方式，适配不同运维环境：

  • Linux 原生：CentOS / Ubuntu，通过 systemctl 管理 nrllink.service
  • Docker 容器：docker pull hicaoc/nrllink:latest，端口映射 80（Web）+ 60050/udp（语音），/data /conf 持久化挂载
  • Windows：直接运行 nrllink_windows_x86_64.exe

Web 管理后台内部监听 TCP 80，通过 nginx 反向代理以 HTTPS 443 对外发布。设备语音/信令使用 UDP 60050。

七、APRS 集成与自动发现

APRS 是什么

APRS（Automatic Packet Reporting System，自动分组报告系统）是业余无线电领域广泛使用的实时数字通信网络，可传播位置、状态、消息等信息，并通过互联网网关（APRS-IS）实现全球汇聚。NRL 系统利用 APRS-IS 实现节点的自动发布与发现，无需手动配置服务器列表。

各类节点的 APRS 标识

APRS 目的地标识对应节点类型
NRLSRVNRL 服务器
NRLBOX马工盒子及爱好者自制硬件终端（ESP32 等）
NRLAPPAndroid / iOS 手机 App（73HAM、NRL互联等）
NRLMP微信小程序客户端

服务器 APRS 上报机制

图 07 — APRS 上报机制时序

APRS 位置包格式

BH4TDV-9>NRLSRV,TCPIP*:!2330.00N/11300.00EI @udp://182.92.158.141:60050,NRL互联服务器
字段说明
BH4TDV-9呼号-SSID（运营者的业余无线电呼号）
NRLSRVAPRS 目的地标识，用于过滤查询 NRL 服务器
TCPIP*经由 APRS-IS 互联网网关发送
!...I位置格式（纬度/经度，I 为符号代码）
@udp://...服务器接入地址，供其他节点自动解析连接

APRS 状态包格式

BH4TDV-9>NRLSRV,TCPIP*:>在线:5,高峰:20,我的NRL平台
字段说明
在线:5当前在线设备数
高峰:20历史最高同时在线设备数
我的NRL平台平台自定义名称

APRS 配置参数

配置项说明示例
APRSServerHostAPRS-IS 服务器地址rotate.aprs2.net
APRSServerPortAPRS-IS 服务器端口14580
CallSign运营者业余无线电呼号BH4TDV
SSID副台标识9
PasscodeAPRS 认证码（留 0 则自动计算）0
SelfAddress本服务器公网 IP / 域名182.92.158.141

Latitude纬度（十进制度）23.5
Longitude经度（十进制度）113.0
Altitude高度（可选）50

爱好者如何通过 APRS 找到 NRL 节点

  1. 访问 aprs.tv 或 aprs.fi
  2. 搜索 APRS 目的地 NRLSRV（服务器）、NRLBOX（盒子）、NRLAPP（App）
  3. 地图上可见所有活跃节点的位置、呼号、在线人数
  4. 点击节点可查看接入地址（udp://IP:60050），输入 App 即可直接连接

九、nrlptt.com 官网服务器发现

服务器启动后自动向 https://nrlptt.com 官网上报自身信息，同时从官网下载全网服务器列表，作为 APRS 机制的补充/备用。

图 09 — nrlptt.com 官网服务器发现流程

上报接口（POST）

POST https://nrlptt.com/api/platform-servers/report
Content-Type: application/json

{"name":"平台名称","host":"182.92.x.x","port":"60050","online":5,"total":20}

获取列表接口（GET）

GET https://nrlptt.com/api/platform-servers

返回全网所有已注册的 NRL 服务器列表，系统自动解析 host:port、过滤自身后加入互联转发列表。

字段说明
name平台名称（取 PlatformName 或 NameShorthand）
host服务器公网 IP 或域名
portUDP 语音端口（通常为 60050）
online当前在线设备数
total历史最高在线设备数（峰值）

典型应用场景

场景一：本地中继台接入全网
本地中继台 → 马工盒子 → NRL服务器A(999房间) → 所有互联服务器(999) → 全网用户
场景二：手机用户与无线电用户通联
手机 73HAM App → 服务器B(1000号房间) ← ESP32终端 ← 本地对讲机(通过马工盒子)
场景三：爱好者监听多地中继台
增强版保姆 → 同时连接 服务器A(999) + 服务器B(1000) + 服务器C(1001) → 多地中继台同步监听
场景四：用户私有通信
用户设备A(房间1) → 服务器(房间1，私有) → 用户设备B(同一用户) — 外部用户无法进入
